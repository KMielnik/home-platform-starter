# Glossary

Short definitions for terms used by this starter kit:

- **VM (virtual machine)** — a guest operating system isolated behind a
  virtual hardware boundary.
- **LXC (Linux Containers)** — an operating-system-level container that shares
  the host kernel while isolating processes and resources.
- **MCP (Model Context Protocol)** — a typed protocol for giving an AI model
  narrowly scoped context or tools.
- **ADR (Architecture Decision Record)** — a dated record of a significant
  choice, the alternatives considered, and how to reverse or revisit it.
- **tailnet** — a private overlay network joining approved devices through
  authenticated encrypted links.
- **STT (speech-to-text)** — converts spoken audio into text.
- **TTS (text-to-speech)** — converts text into spoken audio.
- **idempotent** — safe to repeat because applying the same operation again
  leaves the intended result unchanged.
- **quiesce** — pause writes and activity long enough to take a consistent
  snapshot, backup, or migration point.
